# CHAT Club SRMIST

> **Breach. Defend. Innovate.**

A modern web experience for **CHAT, Community of Hackers and Advanced Technologists at SRMIST**, built around cybersecurity, software engineering, AI, hardware, and hands-on technical exploration.

**Status:** 🚧 In development
**Platform:** Web
**Built with:** Next.js · TypeScript · Tailwind CSS

**[🌐 Live Demo](https://chat-club-srm.vercel.app)** · **[💻 Source Code](https://github.com/Arunan-Kavirajan/CHAT-Club)**

---

## Overview

CHAT is a technical community at SRMIST focused on cybersecurity while exploring the wider technology stack.

The website was designed to communicate that identity through the interface itself rather than presenting the club as a conventional student-organization website.

The experience is built around a technical, cyber-inspired visual language with interactive sections, motion, and a strong emphasis on the club's Red Team, Blue Team, and Advanced Tech divisions.

---

## The Idea

The core philosophy behind CHAT is simple:

> **Understand a system well enough to secure it, or well enough to break it.**

The website extends that philosophy into its design.

Rather than using a typical club website structure, the interface presents CHAT as a technical ecosystem with distinct operational divisions and a strong cyber-inspired identity.

---

## What the Website Covers

### 🔴 Red Team

The offensive security division focuses on understanding how systems break.

Areas include:

* Ethical hacking
* Vulnerability research
* Penetration testing
* CTF competitions
* Exploit development
* Web and network security

### 🔵 Blue Team

The defensive security division focuses on building and protecting resilient systems.

Areas include:

* Digital forensics
* SOC simulations
* Threat hunting
* System hardening
* Incident analysis

### ⚡ Advanced Tech

The club's broader technology division explores areas beyond traditional cybersecurity.

Areas include:

* Full-stack and systems development
* AI and machine learning
* AI/ML security
* Hardware and IoT
* Open-source systems

---

## The CHAT Ecosystem

The website presents the club around three principles:

### Cyber-First, Tech-Wide

Cybersecurity is the core identity, while the club explores software, infrastructure, AI, and hardware across the wider technology stack.

### Hands-On Execution

The focus is on actually building and doing through:

* Attack and defence labs
* Sandbox environments
* Hackathons
* Open-source projects
* Technical experimentation

### Peer-Led Mentorship

The ecosystem is designed around learning from experienced developers and security researchers through workshops, collaboration, and research.

---

## Design Direction

The interface was intentionally designed to feel closer to a technical operations environment than a conventional student club website.

The visual language uses:

* Dark interfaces
* Cyber-inspired typography
* System-style labels
* Strong section hierarchy
* Motion-driven transitions
* Interactive navigation
* Technical terminology
* Red Team / Blue Team visual concepts

The goal was to make the website communicate the club's personality before the visitor even reads the content.
