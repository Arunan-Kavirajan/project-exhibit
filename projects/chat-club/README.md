# CHAT Club SRMIST

> **Breach. Defend. Innovate.**

A modern web experience for **CHAT, Community of Hackers and Advanced Technologists at SRMIST**, built around cybersecurity, software engineering, AI, hardware, and hands-on technical exploration.

**Status:** Completed
**Platform:** Web
**Built with:** Next.js · TypeScript · Tailwind CSS

**[🌐 Live Demo](https://chat-club-srm.vercel.app)**

---

## Overview

CHAT is a technical community at SRMIST focused on cybersecurity while exploring the wider technology stack.

The website was designed to communicate that identity through the interface itself rather than presenting the club as a conventional student-organization website.

The experience combines a cyber-inspired visual language, interactive sections, motion, and a strong emphasis on CHAT's Red Team, Blue Team, and Advanced Tech divisions.

---

## The Idea

The core philosophy behind CHAT is simple:

> **Understand a system well enough to secure it, or well enough to break it.**

The website extends that philosophy into its design.

Rather than using a typical club website structure, the interface presents CHAT as a technical ecosystem with distinct divisions and a strong cyber-inspired identity.

---

## What the Website Covers

### 🔴 Red Team

The offensive security division focuses on understanding how systems break.

Areas include:

- Ethical hacking
- Vulnerability research
- Penetration testing
- CTF competitions
- Exploit development
- Web and network security

### 🔵 Blue Team

The defensive security division focuses on building and protecting resilient systems.

Areas include:

- Digital forensics
- SOC simulations
- Threat hunting
- System hardening
- Incident analysis

### ⚡ Advanced Tech

The broader technology division explores areas beyond traditional cybersecurity.

Areas include:

- Full-stack and systems development
- AI and machine learning
- AI/ML security
- Hardware and IoT
- Open-source systems

---

## The CHAT Ecosystem

The website presents the club around three principles:

### Cyber-First, Tech-Wide

Cybersecurity is the core identity, while the club explores software, infrastructure, AI, and hardware across the wider technology stack.

### Hands-On Execution

The focus is on actually building and doing through:

- Attack and defence labs
- Sandbox environments
- Hackathons
- Open-source projects
- Technical experimentation

### Peer-Led Mentorship

The ecosystem is designed around learning from experienced developers and security researchers through workshops, collaboration, and research.

---

## Design Direction

The interface was intentionally designed to feel closer to a technical operations environment than a conventional student club website.

The visual language uses:

- Dark interfaces
- Cyber-inspired typography
- System-style labels
- Strong section hierarchy
- Motion-driven transitions
- Interactive navigation
- Red Team / Blue Team visual concepts
- Technical terminology

The goal was to make the website communicate the club's personality before the visitor even reads the content.

---

## Responsive Experience

The website was designed to work across desktop and mobile environments.

Responsive layouts and touch interactions were refined alongside the desktop experience rather than treating mobile as an afterthought.

The final implementation adapts the site's visual hierarchy and interactions to smaller screens while preserving the overall identity of the experience.

---

## Engineering Highlights

### Component-Based Architecture

The website is structured around reusable Next.js components, allowing complex sections and interactions to remain modular and maintainable.

### Interactive Experience

Motion and interaction are used throughout the website to reinforce the cyber-oriented identity rather than existing purely as visual decoration.

### Responsive Design

The interface was developed with different screen sizes and interaction methods in mind, including mobile touch interaction.

### Real-World Product Development

Unlike a purely experimental project, this website was built for an actual technical community and required translating an existing organization, its divisions, and its identity into a cohesive digital experience.
